DESIGN FOR ECONOMICS

Spend on judgment.
Reuse the context.

A planning calculator, not a provider invoice. Enter your own verified per-call estimates. Enrichment, subscriptions, media and infrastructure are additional.

Defaults are illustrative assumptions, not quoted market prices. The estimator assumes every eligible account gets Jev and one brief; escalation replaces the routine brief. The CLI only escalates when explicitly configured.

What actually reduces cost

Before a model call

Identity checks, source freshness, opt-outs, future commitments and meeting state run in code. Research and evidence are shared across contacts in one account.

At the API boundary

The local pipeline caps request count and context size, uses an exact-context cache, reserves estimated spend before a call and makes no automatic paid retries.

A request limit is enforced; a dollar estimate is not a guaranteed billing cap. Configure provider-side spending controls separately.
